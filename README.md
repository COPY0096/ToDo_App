Este es mi proyecto de lista de Quehaceres -To Do App-
Deseo crear una aplicacion de escritorio para llevar control de mis tareas en formato de listas
Las listas pueden tener multiples tareas y las mismas subtareas de multiples niveles 
Por cada tarea se debe ser capas de indicar una fecha y hora, fecha limite de finalizacion, detalles
Las tareas se deben poder establecer como una tarea recurrente de repeticion diaria, semanal, mensual, cada x cantidad de dias/meses/años, tambien como cuotas tipo(3 veces a la semana)
